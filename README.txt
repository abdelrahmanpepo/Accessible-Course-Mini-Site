PROJECT 1 — ACCESSIBLE COURSE MINI-SITE

Files:
- index.html: course home and learning outcomes
- staff.html: teaching team
- schedule.html: accessible schedule table
- register.html: accessible registration form
- styles.css: shared responsive stylesheet
- assets/course-outline.txt: downloadable sample resource

How to run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Use the navigation links to visit all four pages.

Important:
This is a working front-end demonstration. Staff names, room details, schedule dates,
and contact addresses are sample content and must be replaced with your real course data.
The form uses browser validation but does not submit to a backend or store data.
Do not present validation, screen-reader, browser, or contrast test results as completed
until you actually run and record those tests.

Course overview

What you will learn

This course introduces the foundations of creating structured, usable, and accessible websites with HTML and CSS.

Learning outcomes

  1. Explain the structure of a web page and the role of HTML.
  2. Use semantic elements to organize content.
  3. Create accessible links, tables, and forms.
    • Write link text that makes sense out of context.
    • Give every form control a label connected with for.
  4. Apply CSS to build clear and responsive layouts.
  5. Test a website with keyboard navigation and validation tools.

The next assessment review is on 1 December 2026. The brief is set out in Web Design and Development — Projects.
